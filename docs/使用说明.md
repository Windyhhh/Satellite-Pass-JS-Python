# JavaScript 调用 Python 卫星过顶函数 - 使用说明

## 📋 项目概述

本项目提供了**三种方式**从 JavaScript 调用 Python 的 `find_satellite_overhead` 函数，用于计算卫星过顶时刻。

### 核心功能
- 根据 TLE（两行轨道根数）数据计算卫星轨道
- 判断卫星何时经过指定地面站上方
- 支持自定义天顶角阈值和时间范围
- 返回所有过顶时刻及持续时间

---

## 🎯 三种调用方式对比

| 方式 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| **Node.js 直接调用** | 本地开发、脚本 | 简单快速、性能好 | 需要 Python 环境 |
| **REST API** | Web应用、生产环境 | 跨语言、可扩展 | 需要服务器 |
| **浏览器 Pyodide** | 演示、原型 | 纯前端、无需后端 | 首次加载慢 |

## 🚀 快速开始

### 方式一：Node.js 直接调用（推荐新手）

#### 1. 安装依赖
```bash
# 安装 Python 包
pip install sgp4 astropy numpy

# 安装 Node.js 包（可选）
npm install
```

#### 2. 运行示例
```bash
node satellite_call_nodejs.js
```

#### 3. 在代码中使用
```javascript
const { findSatelliteOverhead } = require('./satellite_call_nodejs.js');

async function example() {
    const result = await findSatelliteOverhead({
        tle_line1: "1 25544U 98067A   24123.56789012  .00001234  00000-0  12345-3 0  9999",
        tle_line2: "2 25544  51.6432 123.4567 0001234  78.9012 281.2345 15.5432123456789",
        lat: 39.9,           // 纬度（度）
        lon: 116.4,          // 经度（度）
        alt: 0.05,           // 海拔（千米）
        overhead_theta: 10,  // 天顶角阈值（度）
        t_start: "2024-05-03T00:00:00",
        t_end: "2024-05-16T00:00:00",
        time_step: 10        // 时间步长（秒）
    });

    console.log(result);
    // {
    //   overhead_times: ['2024-05-03T12:34:56.000', ...],
    //   start_time: '2024-05-03T12:34:56.000',
    //   end_time: '2024-05-03T12:45:06.000',
    //   duration_seconds: 610
    // }
}

example();
```

## 📊 参数说明

### 输入参数

| 参数名 | 类型 | 范围 | 说明 | 示例 |
|--------|------|------|------|------|
| `tle_line1` | string | 69字符 | TLE第一行数据 | "1 25544U 98067A..." |
| `tle_line2` | string | 69字符 | TLE第二行数据 | "2 25544  51.6432..." |
| `lat` | number | -90 ~ 90 | 地面站纬度（度） | 39.9 |
| `lon` | number | -180 ~ 180 | 地面站经度（度） | 116.4 |
| `alt` | number | ≥ 0 | 地面站海拔（千米） | 0.05 |
| `overhead_theta` | number | 0 ~ 90 | 天顶角阈值（度） | 10 |
| `t_start` | string | ISO 8601 | 搜索起始时间 | "2024-05-03T00:00:00" |
| `t_end` | string | ISO 8601 | 搜索结束时间 | "2024-05-16T00:00:00" |
| `time_step` | number | > 0 | 搜索时间步长（秒） | 10 |

### 返回值

```javascript
{
    overhead_times: [        // 所有过顶时刻（ISO格式字符串数组）
        "2024-05-03T12:34:56.000",
        "2024-05-03T12:35:06.000",
        ...
    ],
    start_time: "2024-05-03T12:34:56.000",  // 首个过顶时刻
    end_time: "2024-05-03T12:45:06.000",    // 最后过顶时刻
    duration_seconds: 610                    // 过顶总持续时间（秒）
}
```

## 🎓 示例代码

### 示例1：查找 ISS 过顶时刻
```javascript
const result = await findSatelliteOverhead({
    tle_line1: "1 25544U 98067A   24123.56789012  .00001234  00000-0  12345-3 0  9999",
    tle_line2: "2 25544  51.6432 123.4567 0001234  78.9012 281.2345 15.5432123456789",
    lat: 39.9,    // 北京
    lon: 116.4,
    alt: 0.05,
    overhead_theta: 10,
    t_start: "2024-05-03T00:00:00",
    t_end: "2024-05-16T00:00:00",
    time_step: 10
});

if (result.overhead_times.length > 0) {
    console.log(`找到 ${result.overhead_times.length} 个过顶时刻`);
    console.log(`首次过顶: ${result.start_time}`);
} else {
    console.log('未找到过顶时刻');
}
```

## 🔧 常见问题

### Q1: 如何获取最新的 TLE 数据？
访问以下网站获取：
- https://celestrak.org/
- https://www.space-track.org/

### Q2: 天顶角阈值如何选择？
- **5-10度**：非常接近天顶，观测条件最佳
- **10-20度**：较好的观测条件
- **20-30度**：一般观测条件
- **>30度**：观测条件较差

### Q3: 时间步长如何选择？
- **5-10秒**：高精度，计算较慢
- **10-30秒**：平衡精度和速度（推荐）
- **30-60秒**：快速计算，精度降低

### Q4: 如何提高计算速度？
1. 增大时间步长（如从10秒改为30秒）
2. 缩小搜索时间范围
3. 使用 REST API 并启用缓存

## 💡 提示

1. **TLE 数据时效性**：TLE 数据会随时间失效，建议定期更新
2. **时区问题**：所有时间使用 UTC 时区
3. **性能优化**：对于长时间范围，建议分段计算
4. **错误处理**：务必添加 try-catch 处理异常
